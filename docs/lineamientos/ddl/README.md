# DDL — DWH OEFA (Oracle BD_CURSOR)

Scripts de creación de tablas para el destino final del modelo dimensional, según
`PROPUESTA_ADAPTADA_ETL.md` (secciones 3 y 4). Corresponden a la carga que hace la capa
lógica (Python) mediante `TRUNCATE + INSERT` hacia Oracle BD_CURSOR.

## Orden de ejecución (obligatorio, por dependencia de FK)

1. **`01_dimensiones.sql`** — 6 dimensiones (`MI_DIM_TIEMPO`, `MI_DIM_ADMINISTRADO`,
   `MI_DIM_ORGANO_UNIDAD`, `MI_DIM_MATERIA_SUBSECTOR`, `MI_DIM_ESTADO`, `MI_DIM_PARAMETRO_UIT`),
   cada una con su miembro `NO ESPECIFICADO` (clave `-1`) ya sembrado.
2. **`02_hechos.sql`** — 2 tablas de hechos (`MI_FACT_MULTA_COERCITIVA`,
   `MI_FACT_INFORME_SUPERVISION`) + 1 tabla de detalle (`MI_DET_ETAPA_MC`). Todas las FK
   hacia dimensiones tienen `DEFAULT -1`.
3. **`03_bitacora.sql`** — tabla `MI_DQ_HALLAZGO`, bitácora de las 5 reglas de calidad
   (R01-R05). Sin FK hacia hechos/dimensiones a propósito: debe poder registrar
   hallazgos incluso sobre filas rechazadas que nunca llegaron a insertarse.
4. **`04_indicadores.sql`** — tabla `MI_INDICADOR_RESULTADO` (K1–K5). Se puebla en
   cada corrida desde la capa lógica (Fase 7); sin FK hacia hechos/dimensiones.

## Notas de compatibilidad

- Motor objetivo: **Oracle 12c o superior** (usa
  `GENERATED BY DEFAULT ON NULL AS IDENTITY`). Si BD_CURSOR corre en una versión
  anterior, reemplazar cada columna identidad por una `SEQUENCE` + `TRIGGER`
  equivalente.
- `MI_DIM_TIEMPO` se crea vacía (solo con el miembro ND); su población con el
  calendario completo se hace con un script de generación aparte, dentro de la
  capa lógica (Fase 5 de `PROPUESTA_ADAPTADA_ETL.md`).
- `MI_DIM_PARAMETRO_UIT` viene sembrada con los valores oficiales del MEF 2015-2025.
  El valor de 2026 queda pendiente de la publicación del Decreto Supremo
  correspondiente (hallazgo H6).
- `MI_DIM_ESTADO` viene sembrada con los estados observados en el diagnóstico de
  fuentes; deben confirmarse/ajustarse con CSEP antes de congelar la homologación
  (Fase 3 del plan de implementación).

## Cómo ejecutar

```sql
-- Desde SQL*Plus, SQLcl o cualquier cliente Oracle conectado al esquema BD_CURSOR:
@01_dimensiones.sql
@02_hechos.sql
@03_bitacora.sql
@04_indicadores.sql
```
